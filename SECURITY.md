# Security Policy

## Supported versions

The latest `main` branch is the only actively supported development version.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's
private vulnerability reporting for the repository, or contact the maintainer
through the email listed in the GitHub profile.

Include:

- affected file and version;
- reproduction steps;
- impact;
- suggested mitigation, if known.

Do not include secrets, Hugging Face tokens, cloud credentials, or private
benchmark infrastructure details in an issue or pull request.
